# Sphinx Kiosk

## Project Description
This project is a self-service kiosk system for ordering food (JavaFX application).

## Current Progress (Week 4)
- JavaFX project setup completed
- SQLite database integrated
- Database connection working
- Tables created:
    - Category
    - MenuItem
- Test data inserted and successfully retrieved

## How to Run the Project
1. Open the project in IntelliJ
2. Run using Gradle:
    - Gradle → app → Tasks → application → run
      OR
    - Terminal: `gradlew run`

## Database
- Database type: SQLite
- File: `kiosk.db` (created automatically when running)
- Initial schema is created in `DatabaseInitializer.java`
